## 📌 Project Overview

Agricultural Crop Yield Analysis is an exploratory data analysis (EDA) project developed using Python to examine agricultural production and crop yield patterns across different Indian states.

The project analyzes crop production, rainfall, temperature, fertilizer consumption, cultivated land area, soil types, and agricultural seasons to identify patterns and generate meaningful insights from the dataset.

## 🎯 Business Objectives

- Analyze total agricultural production across different states.
- Identify crops with higher production and average yield.
- Compare agricultural performance across seasons.
- Explore the relationship between rainfall and crop yield.
- Examine fertilizer usage and agricultural production patterns.
- Understand yield differences across soil types.
- Generate data-driven insights through statistical analysis and visualization.

## 🔍 Analytical Workflow

**1. Data Loading**

**3. Feature Engineering**

**4. Exploratory Data Analysis**
- Performed crop-wise and state-wise production analysis.
- Compared seasonal and soil-wise yield.

**5. Data Visualization**
